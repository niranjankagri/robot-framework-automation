# Robot Framework Test Automation

UI and API test automation with **Robot Framework 7**, **SeleniumLibrary** and **RequestsLibrary**.

- UI under test: [Sauce Demo](https://www.saucedemo.com) (shop: login, products, cart, checkout)
- API under test: [DummyJSON](https://dummyjson.com) (auth, products, carts)

Work in progress: the framework is built step by step; see the commit history.

## Setup

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate    Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
```
